Entra Verified ID – Admin Dashboard (Sample)

This repository contains an exploratory admin dashboard for Microsoft Entra Verified ID, built as a sample project using the Entra Verified ID Admin APIs.

It demonstrates how the Admin APIs can be used to explore, manage, and visualize Verified ID administrative capabilities in a custom UI.

⚠️ Disclaimer

- This is an exploratory sample, not an official Microsoft product
- Not supported by Microsoft 
- Not intended for production use
- APIs and behavior may change without notice
- Use this project for learning, experimentation, and reference only.
